# Soap4Me для Android — APK

[Скачать последнюю версию](https://github.com/nearlynydev/soap4me-android-updates/releases/latest)
для планшетов, телевизоров и головных устройств с Android 9 или новее.
Версия для телефона пока не входит в критерии готовности. Исходный код хранится
в отдельном приватном репозитории; здесь публикуются только подписанные APK.

Установку APK нужно подтвердить средствами Android. После установки приложение
проверяет новые версии при запуске и по кнопке «Проверить обновления» в настройках.
Обновления не устанавливаются без подтверждения пользователя.

Если ранее стояла тестовая debug-сборка, её придётся удалить перед установкой
первого релизного APK: подписи отличаются. Это сбросит локальный вход и настройки,
но история просмотра в аккаунте останется. Последующие релизные APK устанавливаются
поверх прежней релизной версии.

Отпечаток сертификата подписи SHA-256:
`E6:F8:1B:E8:6B:95:AE:D0:F4:2E:45:3B:B4:83:9D:BE:7C:0F:B2:04:78:A0:C6:6A:70:65:EB:8D:E8:3A:F2:46`.
Хеш каждого APK указан на странице соответствующего релиза.

Android-версия всё ещё развивается в сторону полного соответствия macOS-клиенту;
публикация APK не означает, что все сценарии уже перенесены и проверены.
